Rclone Personal Drive Mount

This website documents a personal setup using rclone to access Google Drive and mount files on a privately managed home server.

About this project

Rclone is used to connect Google Drive to the owner's local server for personal file access and media-library management. The configuration and files are managed by the owner.

This website is informational only. It does not offer a public file-hosting service, a user login system, or a Google sign-in form.

Privacy

Information about the use of Google Drive, OAuth authorization, local storage and caching is described in our Privacy Policy.
